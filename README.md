# household-ai

A private home AI setup for a busy family: a machine at home runs local models over
sensitive documents, cloud AI is used where it clearly wins, n8n moves data between
them, and a plain-language runbook means nobody is ever stuck.

Built as a reference implementation of one brief, on made-up household documents.
Nothing here belongs to a real household.
